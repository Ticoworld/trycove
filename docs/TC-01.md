# TC-01 handoff

Trycove's longer-term direction is a connection and needs hub, trial capsules with optional AI assistance, human tester rooms and multiplayer playgrounds, DAO promise-to-proof verification, a missing-piece radar, and optional CKBoost campaigns and rewards. This iteration only implements a narrow connection workspace; future infrastructure is not represented as completed functionality.

## Results and limitations

- A — PARTIAL: 150 CKBDapps Markdown records imported from revision `2b2de54ed5703c4e8efd7b07ce1385cdb8fb8764`, with source URLs and observed timestamps. CKBuilder's README and CKB Pulse's API documentation were inspected, but adapters and cross-source identity resolution are not implemented. Source-local IDs avoid collapsing products sharing a domain or repository. Search covers name and source description, not structured needs or dependencies.
- B — PARTIAL: CellGuard's documented CrowdCell finalize proposal is reconstructed, with source links and explicit unknowns. No new independent opportunity has yet survived research. The minimal exact-concept matcher is not a discovery pipeline; broad keyword matches are not promoted.
- C — PARTIAL: project browsing, search, project profiles, one opportunity, provenance, trial summary and an append-only follow-up ledger exist. Needs, dependencies, outcomes and compatibility cannot yet be structured or edited comprehensively. Localization is limited to a few labels. No user authentication or moderation exists.
- D — PARTIAL: 11 pinned upstream CellGuard bridge tests passed independently against synthetic fixtures and mocked RPC. This is not an end-to-end CrowdCell integration, real pledge, on-chain validation or rebuild/contention test. See the evidence record.

## Architecture and provenance

Next App Router renders server-side from Drizzle tables, using PGlite locally or node-postgres when `DATABASE_URL` is set. SQL migration is versioned; sync parses source front matter with Zod, sanitizes external URLs, and upserts by upstream filename. The source record is an imported claim, not a verified fact. A manually curated CellGuard project and opportunity cite pinned public source files. The ledger accepts validated bounded text and React escapes it. No code execution or outbound contact is performed by the app.

Before production, add authentication, authorization, abuse controls, migration tracking, multi-source identity review, structured capabilities and compatibility evidence, robust source history and refresh handling, full localization, and a real PostgreSQL deployment test. A missing-piece radar needs evidence-based classification rather than inferring ecosystem gaps from failed tests.
