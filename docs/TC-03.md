# TC-03 handoff workflows

TC-03 adds two source-bounded handoff paths:

- A tester with the private Guided Trial cookie can preview a separate feedback report, select exactly which notes are included, and publish or revoke that copy. The private session and append-only receipts are not modified. A session-authorized export downloads only the approved report JSON and its content digest; it excludes the private cookie, session token, receipt JSON and unapproved notes.
- An organizer can publish a Connection Brief only from a saved consumer/provider capability. The brief preserves evidence links and revisions, unknowns, prerequisites and its hypothesis boundary. Publishing a URL records that the brief was prepared; it does not record that an introduction was sent.

Follow-up records are append-only. Only events and notes deliberately approved for the public timeline appear on shared report pages. A reported reply, fix, retest or integration is an organizer-entered event, not independent verification.

## Organizer access boundary

In the local application, `TRYCOVE_WRITE_KEY` authorizes organizer sign-in at `/organizer`. Successful sign-in issues an eight-hour, HTTP-only, same-site cookie signed with that server key. The key is never rendered into Results, opportunity pages or public briefs. Rotating the key invalidates active organizer cookies.

Before public deployment, replace this shared-key local organizer mechanism with named account or organization authorization, per-user access and appropriate CSRF/session revocation controls. Do not reuse a development key in a hosted environment. No bulk local-to-hosted database copy is provided; review and export only the approved report, then deliberately import that report into the hosted system.
