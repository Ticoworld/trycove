# Cross-project offline experiment

On 2026-11-16, Node v24.22.1, `scripts/run-cross-trial.sh` cloned CellGuard `2bb3182adb1a5d00bca24e2068f790a50e8e2d70` and CrowdCell `0835ad42decf2c9594fa92a185eea4cee9eba622`. It ran CrowdCell's campaign serializer and status update to construct synthetic campaign output data, inserted that data into CellGuard's synthetic finalize fixture, and ran CellGuard's actual offline preview. The original returned `PREVIEW_ONLY`; lowering the output capacity returned `POLICY_FAILED`; a separately constructed modified transaction was checked again and returned `POLICY_FAILED`.

This checks a data-format and offline policy boundary. It does not execute CrowdCell's builder, chain scripts, a real pledge, or the automatic contention retry, and does not establish live compatibility. No real deployment identifiers, RPC or broadcast were used. CrowdCell's `finalizeCampaign` currently calls `signer.sendTransaction` after fee completion, whereas CellGuard's guarded helper requires separate `signTransaction` and client send calls. An actual integration must change that boundary and revalidate each rebuilt transaction with a reviewed deployment-specific policy.
